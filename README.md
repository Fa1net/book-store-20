# Покупка книг онлайн

Контрольна робота 1. Варіант 20.
Стекольщіков Георгій, 491 група.

У проєкті три файли:
- `index.html` — сторінка з книгами та підрахунком суми;
- `book-order.bpmn` — діаграма оформлення замовлення;
- `README.md` — короткий опис роботи.

Для запуску достатньо відкрити `index.html` у браузері. Вказати кількість книг, вибрати самовивіз або доставку та натиснути «Розрахувати суму». Ціни умовні, доставка — 60 грн.

Діаграму можна відкрити у Camunda Modeler.
Зміни з доставкою виконано у гілці `feature/update-book-store-20`, потім її злито з `main`.
