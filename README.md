# Покупка книг онлайн

Контрольна робота 1, варіант 20. Стекольщіков Георгій, група 491.

Відкрийте index.html у браузері. Сторінка працює без сервера та залежностей.
Вкажіть кількості від 0 до 99 і натисніть «Розрахувати суму».
Ціни наведено для навчального прикладу; платежі не виконуються.

Модель book-order.bpmn містить Collaboration Diagram BPMN 2.0.
Відкрийте файл у Camunda Modeler або https://demo.bpmn.io.

Гілка функції: feature/update-book-store-20.
